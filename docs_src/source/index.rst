BrainMaze - Torch (superseded by brainmaze-eeg-models)
=======================================================

.. important::

   **brainmaze-torch is superseded by** `brainmaze-eeg-models <https://github.com/bnelair/brainmaze-eeg-models>`_
   (`documentation <https://bnelair.github.io/brainmaze-eeg-models/>`_,
   ``pip install brainmaze-eeg-models``). Version 0.3.0 is the final release, a compatibility shim
   that re-exports brainmaze-eeg-models with a ``FutureWarning``; the repository will be
   archived after it. How to move your code:
   `migration notes <https://bnelair.github.io/brainmaze-eeg-models/seizure.html#moving-from-brainmaze-torch>`_.
