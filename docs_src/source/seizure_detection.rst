Seizure Detection (deprecated shim)
====================================

``brainmaze_torch.seizure_detection`` re-exports :mod:`brainmaze_eeg_models.seizure`; the API
reference is in the `brainmaze-eeg-models documentation
<https://bnelair.github.io/brainmaze-eeg-models/seizure.html>`_. ``brainmaze_torch.models_generic``
was removed (importing it raises ``ImportError``).
